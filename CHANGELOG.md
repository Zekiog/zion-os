# Changelog

All notable changes to ZIONOS are documented here. Versions follow [SemVer](https://semver.org/).

## [2.0.0] — 2026-08-31

### Added
- Six-layer enterprise architecture: Trust → Memory → Operations → Vertical → Observability → Governance.
- Five research-driven connection specs:
  1. Semantic Layer + Knowledge Graph
  2. Multi-Tenant Isolation + RLS
  3. Distributed Tracing + OpenTelemetry
  4. AI Governance + Compliance Framework
  5. Federated Learning + Edge Coordination
- Six-phase roadmap (Aşama 1–6) with quantified impact targets.
- Component catalog mapping every ZIONOS component to its layer.

### Strategic basis
Synthesized from the Board's 2026-Q3 assessment: Agentic OS patterns,
event-driven capability security, OpenTelemetry distributed tracing,
semantic-layer architectures, multi-tenant RLS, and AI governance frameworks.
